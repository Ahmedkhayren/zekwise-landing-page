# Zekwise

A modern, responsive landing page for an AI-powered document product, built as a portfolio project to demonstrate frontend development, responsive design, and production deployment.

🌐 **Live Demo:** https://zekwise-landing-page.vercel.app/

## Overview

Zekwise is a modern SaaS-style marketing website designed to present an AI document product with clear visual hierarchy, strong calls to action, responsive layouts, and a polished interface.

The project demonstrates my ability to turn a product concept into a clean, production-ready frontend experience.

## Features

- Responsive desktop, tablet, and mobile layouts
- Modern SaaS landing-page design
- Clear hero section and calls to action
- Reusable UI components
- Responsive navigation
- Product and feature sections
- Clean typography and spacing
- Production deployment on Vercel

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## Local Development

Clone the repository:

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
cd <YOUR-REPOSITORY-FOLDER>

Install dependencies:

npm install

Start the development server:

npm run dev

Open:

http://localhost:3000
Production Build

Create an optimized production build:

npm run build

The project has been tested with a successful production build before deployment.

The application is deployed with Vercel.
```
